PROJECT PILOT — INSTALL 1 IMAGE + FASTER AI UPDATE
===================================================

1. Extract this ZIP.
2. Open the project-pilot repository on GitHub.
3. Click Add file -> Upload files.
4. Upload everything INSIDE the extracted folder to the repository root.
5. Allow matching files to be replaced.
6. Commit with:

   Reduce image cost and speed up Su

7. Wait for Vercel to deploy.
8. In Vercel -> Settings -> Environment Variables, update these Production values:

   OPENAI_IMAGE_MODEL=gpt-image-2
   OPENAI_IMAGE_QUALITY=medium
   OPENAI_ASSISTANT_MODEL=gpt-5.4-mini

9. Redeploy the newest deployment after changing the variables.
10. Hard-refresh Project Pilot with Ctrl + Shift + R.
