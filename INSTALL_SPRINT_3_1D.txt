INSTALL
-------
1. Extract this ZIP.
2. Open the project-pilot repository on GitHub.
3. Click Add file -> Upload files.
4. Upload EVERYTHING INSIDE the extracted folder to the repository root.
5. Allow matching files to be replaced.
6. Commit with:

   Sprint 3.1D Brand Unification and Vision Polish

7. Wait for Vercel to show the deployment as Ready.
8. Hard refresh Project Pilot with Ctrl + Shift + R.
