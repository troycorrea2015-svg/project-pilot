# Project Pilot Sprint 3.1C — Permit Concierge

Sprint 3.1C adds the human operating layer needed for Project Pilot to relieve homeowners from most permit administration.

## Homeowner experience

The homeowner chooses the help they need, authorizes review/preparation/coordination, and sees two clear lists:

- **Project Pilot is handling**
- **Your action is needed**

The homeowner can send messages, complete required tasks, and follow the case from intake to closeout.

## Admin experience

The admin queue links to a dedicated workbench with assignment, status, tasks, homeowner communication, case details, public summary, and internal notes.

## Scope boundary

This is a human-assisted concierge workflow. Actual government filing remains subject to each jurisdiction's applicant, identity, authorization, payment, signature, notarization, contractor-license, and professional-seal rules.
