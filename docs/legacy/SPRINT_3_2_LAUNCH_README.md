# Sprint 3.2 Launch Candidate

A controlled public-launch release for Project Pilot.

## Added
- Admin launch-readiness diagnostics
- Authenticated launch support queue
- Branded page and application error recovery
- Public health endpoint
- Security response headers
- Sitemap, robots, manifest, and richer metadata
- Founding-launch messaging and clear product boundaries
- Cumulative latest Project Vision, Su, Permit Autopilot, Permit Concierge, and brand files

## Not automatically enabled
- Marketplace payments
- Government portal automation that bypasses applicant identity or agency rules
- Custom SMTP or CAPTCHA; those are Supabase dashboard settings and must be confirmed manually
