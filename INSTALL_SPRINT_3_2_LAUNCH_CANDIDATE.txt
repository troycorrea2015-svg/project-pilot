INSTALL
1. Extract this ZIP.
2. Open the project-pilot repository on GitHub.
3. Click Add file -> Upload files.
4. Upload everything INSIDE the extracted folder to the repository root.
5. Allow matching files to be replaced.
6. Commit with: Sprint 3.2 Launch Candidate
7. Wait for Vercel to show Ready.
8. Run RUN_THIS_IN_SUPABASE_014.sql once in Supabase SQL Editor.
9. Redeploy after confirming Production environment variables.
10. Hard refresh with Ctrl + Shift + R.
