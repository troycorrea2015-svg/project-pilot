# Sprint 3.4 — First-Run Simplicity Update

This patch does not promise that every user will experience zero technical issues. It reduces the most likely first-use confusion by making the product lead users through one clear path.

## Dashboard changes
- Adds a first-visit welcome guide.
- Reduces the primary choices to three: continue/start a project, prepare a permit, or visualize the result.
- Moves contractors and help into secondary actions.
- Uses simpler sidebar labels.
- Hides advanced dashboard sections until the user has created a project.
- Allows the guide to be reopened from the sidebar.

## Project workspace changes
- Renames navigation in plain English.
- Adds a first-visit project guide.
- Adds a four-step “Simple Path” at the top of Start Here.
- Adds a persistent “How this works” button.

## Permit application changes
- Rephrases the builder as three clear steps:
  1. Check answers
  2. Create application
  3. Enter official portal
- Uses clearer action labels and supporting explanations.

## Database changes
None. This patch expects Sprint 3.3 migration 015 to already be installed.
