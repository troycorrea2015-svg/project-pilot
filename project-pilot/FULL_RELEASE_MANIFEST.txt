ADAPTIVE PERMIT EXPERIENCE
--------------------------
- No universal Upload Plans step.
- Project Pilot first identifies the permit route and requirements.
- Plans, surveys, drawings, IDs, municipal approvals, and supporting files are requested only when confirmed/appropriate for the project and jurisdiction.
- If no mandatory upload has been confirmed, the customer is explicitly told they can continue.
- If a file is required, Project Pilot explains what it is, why it is needed, and lets the customer upload it when available.
- Verified required files/answers can still block authorization so the workflow does not bypass real jurisdiction requirements.
- Customer-facing journey: Permit Route → Project Details → Requirements → Prepare & Review → Submit & Track.
