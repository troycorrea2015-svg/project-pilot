# Project Pilot 4.2 — Easier by Design

4.2 keeps the complete 4.1 free-first revenue system and updates the customer experience around one principle: **the user should not have to understand permitting before Project Pilot can help them.**

## Approved visual direction
- Warm, welcoming, modern light interface inspired by the approved Option 5 concept.
- Exact folded-blue Project Pilot logo supplied by the owner; substitute house/check logos are not used.
- Project-type hero carousel for Kitchen, Bathroom, Deck, Addition, Shed/Garage, and Fence.
- Clear single-action language and less permit jargon.

## Permit-flow improvement
“Upload Plans” is no longer a universal required step. Project Pilot first gathers project details and determines requirements. A plan, survey, drawing, approval, or other file only blocks the workflow when that requirement has been confirmed for the project/jurisdiction. Recommended files can still be saved early.

## Revenue model retained
- Free homeowner self-service: $0.
- Permit Concierge: $99 base one-time fee.
- Give $10 / Get $10 Project Pilot service credits.
- Contractor introduction-fee marketplace remains available.
- Government fees and licensed-professional costs remain separate.
